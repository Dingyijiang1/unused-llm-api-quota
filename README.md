# 102 free LLM API tiers, and a market for unused keys

Most teams top up before they check what is already free.

Across 627 models and 3,498 channel listings, 102 carry a free quota. By count:

| Provider | Listings | Typical cap |
| --- | --- | --- |
| Nvidia | 27 | 40 req/min |
| OpenCode | 14 | 50/day |
| Pendra | 12 | self-hosted |
| UnoRouter | 11 | 1 req/min |
| Atomic Chat | 8 | local, unlimited |
| Google AI Studio | 7 | free tier, rate limited |

The caps are count-based, not token-based. That is enough to validate prompts, latency and output quality, and not enough to run a product on.

The other half is waste. Monthly plans expire with balance left, and the balance gets written off because nobody owns the resale. That quota can be listed instead, if three things are stated: how much is left, when it expires, and the minimum lot. Buyers keep funds in escrow until a real call with their own key succeeds.

Both live at [llmrankhub.com](https://llmrankhub.com).
